# Visualizador de Sistema Solar em Realidade Aumentada (RA)

Este projeto é um visualizador 3D interativo dos planetas do sistema solar. Use as teclas `→` e `←` para alternar entre os planetas renderizados.

## Tecnologias
- Python
- PyOpenGL
- Pygame

## Como executar

1. Clone o repositório
2. Instale as dependências:    

´´´bash
pip install -r requirements.txt
´´´  
3. Rode a aplicação:  

python src/main.py
